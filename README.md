## 🛠️ Setup Walkthrough

We have designed the initial setup to be as smooth as a perfectly timed web-swing. Follow these steps and you will be fully operational in minutes.

### Step 1 — Prepare Your Environment
Ensure Marvel's Spider-Man 2 is installed and has been launched at least once. This allows the Companion to correctly identify your game directory and configuration files during setup.

### Step 2 — Retrieve the Package
Use the access point provided above. Save the package to a location you will remember, such as a dedicated folder on your primary drive.

### Step 3 — Unpack the Contents
Extract the package using your preferred archive utility. Windows 11 users can typically right-click and choose the built-in extraction option. Place the resulting folder somewhere permanent — not inside a temporary directory.

### Step 4 — Launch the Companion
Navigate into the extracted folder and run the main application executable. On first launch, Windows may present a security prompt; this is expected behavior for newly encountered applications and can be safely allowed after verifying the source.

### Step 5 — Guided First-Run Configuration
The Companion will greet you with a friendly onboarding wizard. It will:
- Detect your Windows version and language.
- Locate your Marvel's Spider-Man 2 installation automatically.
- Offer to create a default profile suited to your selected playstyle.
- Explain each available module in plain language.

### Step 6 — Personalize Your Experience
Explore the settings panel at your leisure. Every option includes an inline description, and nothing is applied until you confirm. Experiment freely — the automatic backup system has your back.

### Step 7 — Begin Your Adventure
With your profile configured, launch Marvel's Spider-Man 2 as usual. The Companion runs quietly alongside, applying your preferences in real time.
